
# 🤖 JavaScript Coding Fun Fact Bot

## 📌 About the Project
JavaScript Coding Fun Fact Bot is a beginner-friendly console-based project developed using JavaScript as part of my freeCodeCamp JavaScript Certification journey.

The bot introduces itself and shares interesting facts about JavaScript programming.

## ✨ Features
- Displays a welcome message.
- Introduces the chatbot.
- Shares three interesting JavaScript facts.
- Displays a goodbye message.

## 🛠️ Technologies Used
- JavaScript
- Node.js (for running the program)

## 📚 JavaScript Concepts Practiced
- Variables using `let` and `const`
- Console output using `console.log()`
- String concatenation
- Variable reassignment
- Basic programming logic

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
node script.js
```
